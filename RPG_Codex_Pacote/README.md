# RPG digital — pacote de contexto para Codex

Atualizado em **23/10/2026**. Este pacote é uma fotografia das decisões tomadas no planejamento criativo com o usuário. **Não é um projeto de código, uma engine escolhida ou uma ordem para implementar tudo.**

## Onde começar

1. Leia `AGENTS.md` (instruções de trabalho para o Codex).
2. Leia `docs/GDD.md` (descrição do jogo e regras atuais).
3. Use `docs/DECISOES.md` para diferenciar **confirmado**, **proposto** e **futuro**.
4. Consulte `docs/PENDENCIAS.md` antes de transformar detalhes em código.
5. Use `PRIMEIRO_PROMPT_CODEX.md` como texto sugerido para a primeira conversa no Codex.

## Como integrar

- Se **ainda não há repositório**, crie uma pasta para o jogo e extraia o conteúdo deste pacote na raiz.
- Se **já existe um repositório**, copie os arquivos para a raiz **sem sobrescrever automaticamente** um `AGENTS.md` já existente; concilie as instruções se necessário.
- Abra a pasta como workspace no Codex e inicie uma nova conversa. O Codex reconhece `AGENTS.md` na hierarquia do projeto, enquanto os demais arquivos servem de referência.
- Se a documentação for alterada, mantenha o histórico de decisões atualizado. Nunca trate exemplos numéricos ou ilustrativos como valores de balanceamento aprovados.

## Escopo de momento

O foco atual é consolidar mecânicas, obter decisões de tecnologia/escopo e posteriormente criar **um protótipo pequeno e testável**. História, motor, estilo de arte, plataformas e valores definitivos ainda não foram escolhidos.

## Referências criativas

*Breath of Fire I* (especialmente exploração por habilidades individuais e sprites dos quatro companheiros na fila) e *Chrono Trigger* (ritmo ATB, grupo e encontros espacialmente interessantes). A intenção é **inspiração, sem copiar** personagens, arte, cenas ou conteúdo protegido.
