# Mensagem inicial sugerida ao Codex

Leia `AGENTS.md`, `README.md` e todos os arquivos em `docs/`.

Este repositório é de um RPG digital que estamos planejando criativamente no ChatGPT. Os documentos representam as decisões aprovadas até agora. Respeite a distinção entre regras confirmadas, propostas e ideias futuras.

**Nesta primeira interação, não programe ainda.**

1. Faça um resumo fiel dos pilares de gameplay e dos invariantes já aprovados.
2. Identifique as decisões técnicas mínimas que faltam para começar um protótipo jogável (especialmente engine, plataforma e recorte da primeira entrega).
3. Sugira uma arquitetura simples e orientada a dados para: equipes e exploração, encontros/presets determinísticos, batalha ATB, movimento em loop de inimigos, animações com retorno à posição lógica e IA de escolha de alvos ponderada.
4. Proponha um primeiro *vertical slice* enxuto com critérios de aceite verificáveis, sem incluir ideias de conteúdo futuro.
5. Espere minha aprovação antes de criar o projeto ou escrever código substancial.

Não invente conteúdo da história, personagens definitivos ou números de balanceamento. Trate este GDD como fonte de requisitos até receber atualizações.
